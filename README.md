# Robust Multi-Agent Traffic Control Under Non-Stationarity

This repository contains a SUMO-based research prototype for traffic-signal control, anomaly detection, and stress testing. The current codebase is usable for smoke tests and controlled experiments, but not all generated artifacts are publication evidence.

## Current Verified Status

- Python source compiles with `python -m compileall -q src scripts`.
- Core imports under `src/` load successfully in the current environment.
- Setup smoke test passes with `python scripts/test_setup.py`.
- Phase 1 smoke evaluation passes with `python scripts/test_phase1.py`.
- Phase 2 synthetic anomaly training/evaluation passes with `python src/phase2/anomaly_trainer.py` and `python scripts/test_phase2.py`.
- Phase 3 structural and short stress smoke tests pass with `python scripts/test_phase3_integration.py` and `python scripts/test_phase3.py`.

## Evidence Rules

- `archive/unverified_evidence/` contains demo or previously invalid outputs. Do not cite those files as benchmark evidence.
- `outputs/benchmark_results.json` is only valid if generated by a current benchmark run and not marked `presentation_demo`.
- `results/*` tables are generated from current `outputs/*`; missing experiments are marked as `not_run` or `missing`.
- Phase 2 metrics from `scripts/test_phase2.py` are synthetic-data checks unless the model and dataset are replaced with real labeled traffic data.

## Common Commands

```bash
python scripts/test_setup.py
python scripts/test_phase1.py
python src/phase2/anomaly_trainer.py --epochs 5 --output_dir outputs/phase2
python scripts/test_phase2.py
python scripts/test_phase3_integration.py
python scripts/test_phase3.py
python scripts/generate_publication_artifacts.py --mode quick
```

For stricter reproducibility:

```bash
python scripts/reproduce_main_results.py --mode quick
python scripts/run_publication_suite.py --mode quick
```

Use `--mode full` only when SUMO, checkpoint compatibility, and runtime budget have been verified.

## Repository Layout

- `configs/`: experiment configuration.
- `src/`: model, environment, training, evaluation, and dashboard code.
- `scripts/`: smoke tests, orchestration, reporting, and diagnostics.
- `docs/`: protocol, limitations, and project notes.
- `results/`: generated tables and summaries from current outputs.
- `archive/unverified_evidence/`: quarantined demo/invalid artifacts.
