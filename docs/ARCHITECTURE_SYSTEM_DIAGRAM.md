# Whole-Framework Architecture and System Diagram

This document provides publication-ready descriptions for the complete framework implemented in this repository. The diagrams are grounded in the actual repository structure:

- `src/phase1/`: traffic control environment, MAPPO/PPO training, graph-based observations, evaluation
- `src/models/`: ST-GNN forecaster, predictive GNN-RL bridge, MAPPO policy
- `src/phase2/`: anomaly detector training and scoring
- `src/phase3/`: anomaly-aware integration and risk-aware adaptation
- `scripts/`: benchmarking, publication suite orchestration, artifact generation
- `results/`: tables, figures, summaries, and dashboard-facing outputs

## Architecture Summary for Manuscript Use

The complete framework is organized as a layered research system for robust traffic signal control under non-stationarity. At the bottom, the SUMO simulator and TraCI interface provide network dynamics, lane-level telemetry, and signal actuation. Above this layer, graph construction and feature extraction convert intersection traffic states into structured node representations. A spatial-temporal GNN then performs relational and temporal modeling to forecast short-horizon traffic evolution and construct latent state embeddings.

These forecast-aware embeddings are consumed by a multi-agent reinforcement learning controller implemented with PPO/MAPPO-style centralized training and decentralized execution. The controller outputs per-intersection phase actions, while reward computation incorporates waiting time, queue length, speed, and optional risk-aware penalties. Phase 2 adds anomaly detection through a spatial-temporal autoencoder trained on traffic sequences, and Phase 3 integrates anomaly scores, adaptive thresholds, and risk modeling into the traffic control loop to improve robustness under disturbances such as accidents, sensor failures, and demand shifts.

At the evaluation layer, the framework runs standardized comparisons against fixed-time, random, actuated, and learning-based baselines, together with ablation, latency, generalization, and stress benchmarks. These experiments are orchestrated by the reproducibility and publication scripts, which materialize final tables, figures, summaries, and dashboard outputs in a form suitable for publication.
