# Documentation Curation

Not every markdown file needs to stay in the repository root.

## Keep as Core (active publication path)

- `README.md`
- `docs/EXPERIMENT_PROTOCOL.md`
- `docs/REPRODUCIBILITY.md`
- `docs/APPENDIX_SEEDS.md`
- `docs/LIMITATIONS.md`

## Keep as Supporting (optional but useful)

- `PROJECT_REPORT.md`
- `Capstone_Mega_Report.md`
- `Presentation_Slides_Outline.md`

## Archive Candidates (legacy/draft/progress-heavy)

Progress snapshots, old planning notes, duplicate report drafts, and temporary submission checklists should be moved to `archive/` once the final publication package is frozen.

This keeps the repository professional while preserving history.
